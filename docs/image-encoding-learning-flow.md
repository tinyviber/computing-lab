# 图像编码：四步引导流程

## 设计目标

图像编码保留真实的图像模型：源图像经过空间采样，再经过颜色表示，最后生成同尺寸重建图像。页面用一个 feature-local 的四步流程安排操作顺序，让第一次进入页面的人先只处理一个变量，再逐步比较颜色表示、格式和数据量。

页面不判断学生是否“学会”。每一步只由实际操作解锁下一步；页面状态记录的是控件是否已经被操作过，不是答题分数。

## 四步操作

| 步骤 | 操作                                                               | 解锁规则                                               |
| ---- | ------------------------------------------------------------------ | ------------------------------------------------------ |
| 1    | 改变空间采样百分比，观察采样尺寸和重建图像                         | 初始唯一可操作的课程控件；采样百分比发生真实变化后完成 |
| 2    | 先切换到调色板，再调低颜色位深，观察颜色层次                       | 第 1 步完成后开放；把调色板位深调低后完成              |
| 3    | 选择未压缩 / 原始、PNG、JPG / JPEG 或 WebP                         | 第 2 步完成后开放；选择任一格式后完成                  |
| 4    | 编辑宽度、高度、每像素位数，计算原始数据量并查看所选格式的教学估算 | 第 3 步完成后开放                                      |

第 1 步之前，采样网格相位、视图标签、画布位置选择、颜色表示、上传、格式按钮和计算器都会显示为锁定状态，并且事件处理也会拒绝这些操作。第 1 步完成后，视图、画布位置选择、相位和上传开放；颜色控件仍等到第 2 步开始。第 2 步完成后才开放格式，第 3 步完成后才开放计算器。

默认颜色表示是原色 RGB24，所以初始图像不是调色板图像。URL 中的颜色参数不会跳过这一步；必须先完成采样，再切到调色板并把位深调低。旧的 `image=gradient`、`image=checkerboard`、`image=text-edge`、`image=pixel-grid` 和 `scenario=low-sampling` 等情境参数仍用于复现实验配置。

## 状态和重置

`src/features/image-encoding/lesson/state.ts` 只在本功能内保存 `samplingChanged`、`colorAdjusted`、`formatSelected` 和 `selectedFormat`。Reducer 会在动作入口检查前置步骤，因此直接派发一个锁定动作也不能跳过顺序。

- URL 只提供样例、采样值、位深、相位、视图和颜色表示等配置，不提供进度。
- 采样值与当前值相同的事件不会伪造第 1 步完成；键盘和触摸范围控件产生的真实值变化同样有效。
- 恢复初始情境、URL 情境变化和成功载入图片都会清空三项进度。上传成功后颜色表示回到 RGB24、格式回到未压缩 / 原始，仍需重新改变采样百分比。
- 上传输入在第 1 步前禁用，避免第一次操作同时面对源图选择和采样设置。

## 图像模型的观察点

- 采样后的编码单元数量会变少，重建图像仍保持源图像的显示尺寸；这不是 CSS 缩放。
- 调色板模式用 `b` 位颜色编号，最多有 `2^b` 个颜色。RGB24 模式直接保留三个 8 位颜色通道。
- 视图和像素详情在第 1 步完成后可用，帮助比较源坐标、采样格、颜色表示和二进制值。
- 相位只在相应方向没有达到完整采样密度时起作用；完整密度的方向固定为 0。

## 数据量和格式估算边界

原始像素数据量使用明确公式：

```text
rawBits = sampledWidth × sampledHeight × bitsPerPixel
rawBytes = ceil(rawBits / 8)
```

模型里的 `rawPayload` 是理论像素数据量，不是浏览器生成的 PNG、JPEG 或 WebP 文件大小。格式卡片和计算器显示的“教学估算”来自 feature-local 的确定性格式模型，只用于比较当前采样表示；它不是对任何浏览器或编码器输出的承诺，也不使用虚构的“压缩比”。

真实文件字节数会受图像内容、编码器设置、文件头、颜色表、元数据和具体格式实现影响。计算器会安全地把空值、非数字、非整数和超出范围的输入归一化后再计算，并同时显示原始位数、原始字节和所选格式的教学估算。

## 保留的兼容能力

页面仍保留固定样例、兼容情境 URL、本地图片上传、源图和重建图对比、采样/量化/表示/差异视图、相位几何说明和像素详情。它们服务于四步流程，但没有额外的连续任务清单、观察轨迹或全局课程运行时。
