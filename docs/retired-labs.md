# 已退役实验的 idea 记录

> 2026-09：运行时只保留「实现ALU」（`calculator`）。下面记录被移除实验的
> 问题意识和课堂想法，不是当前路由、API、数据格式或实现承诺。重新实现任何一项
> 之前，应重新确认课程目标、教师使用场景和最小可验证交互。

## 为什么集中记录

这些实验曾经各自拥有 domain、lesson、UI、路由、测试和（部分实验）服务端持久化。
它们验证了不少有价值的课堂问题，但没有形成当前产品必须承担的运行时能力。分散在
课程设计、研究输出和旧路由中的记录会让人误以为这些能力仍受支持，所以只保留这一份
面向未来的 idea 摘要。

## 退役实验

| 实验         | 曾经想教什么                                            | 值得保留的课堂 idea                                                                                                                                                 |
| ------------ | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 图像编码     | 采样、量化、bit 约定和信息损失；AI 修复是否找回真实信息 | 用同一张图做“原图 → 编码 → 重建/修复”的对照；把 raw bit budget 与实际压缩格式明确分开；让学生修改原图但保持编码签名不变，观察多对一损失；URL 只描述可复现实验情境。 |
| 声音编码     | 采样率、Nyquist、混叠、量化误差                         | 原始/重建声音 A/B 对照，一次只改一个参数；同时展示波形、采样点、折叠频率和量化级数；没有人为的完成徽章，听觉观察本身就是证据。                                      |
| 家庭网络配置 | 设备地址、ARP、网关、路由和 NAT 的因果链                | 先发探针找出第一处失败，再修改配置，第二次发送同一目标并与历史快照比较；把“超时”与“目标不存在”区分开；探针历史是证据而不是全局工作流。                              |
| 二进制补码   | 定宽 word、无符号/有符号解释、逐列 ripple carry、溢出   | 同一 bit pattern 同时显示两种解释；把 carry-out 和 signed overflow 分开；按位按钮和逐列证据比直接显示十进制结果更适合课堂。                                         |
| 程序执行     | 变量、while 条件、循环体、输出和运行时错误              | 用固定小程序逐步执行，每一帧显示 before/after 环境、控制位置和输出；预测是可选观察，不阻塞执行；“变量变化”和“循环停止”是局部因果检查点。                            |
| 协议过程     | 延迟、丢包、超时、重试、确认和重复抑制                  | 用确定性事件队列让学生逐事件观察；超时只说明 ACK 缺失，不证明接收方失败；对比 ACK 丢失、请求丢失和接收方静默三类情境。                                              |
| UTF-8 编码   | Unicode 码点、变长模板、payload 分组和累计字节数        | 一次推进一个 code point，同时展示标量值、分支、模板位和输出字节；用 ASCII、重音、CJK、emoji 及边界值对比“字符数不等于字节数”。                                      |
| 蒙特卡洛求 π | 随机抽样、四分之一圆、估计误差和收敛                    | 固定 seed 的可重复随机流；按 batch 逐步运行，观察累计 inside/total、估计值和误差；相同样本量换 seed，比较轨迹而不是追求一次结果。                                   |
| 关系数据     | 投影/过滤/连接/聚合、类型、约束和来源行                 | 把 `NULL` 与空字符串分开；每个结果行携带来源行/provenance；选择结果行时反查来源表；派生计数标明“计算得到”，约束失败保留可解释证据。                                 |
| 字节编辑     | 有限表示的可编辑性、UTF-8 合法性和单字节干预            | 先预测一次编辑是否仍合法，再应用一个 byte edit；展示前后完整字节、有效字符或精确违规位置；编辑历史是特性内的因果记录，不需要通用文本编辑器或共享 BitGrid。          |

## Slidev / 在线课件尝试

`lessons/excel-01` 曾尝试把“Excel 2003 第一课：把空白表做成成绩表”做成 Slidev
在线课件。核心想法是先让学生看见终点，再观察空白表与成品的差距，按“自己找 →
给线索 → 给方法”推进标题合并居中、格式调整、学号续写和公式计算。浏览器编辑器
提供 Markdown/Vue/CSS 编辑、保存到课程目录和 Slidev 热预览。这个交付形态增加了
独立编辑服务、预览进程、静态 deck fallback 和额外依赖；它不再属于当前运行时。

## 重新实现的门槛

这些记录不构成待办列表。只有在有明确课程/教师需求、独立的 feature owner、可观测
的最小交互和对应验证边界时，才重新建立一个 feature。不同实验的状态机、证据形状、
URL 语义和时间模型应继续留在 feature 内；不要因为这些 idea 曾经相似，就恢复一个
通用 `LessonRuntime`、`Stepper`、`ScenarioCodec`、`Validator`、`BitGrid` 或共享
语义工作流。
