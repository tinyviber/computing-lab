# 图像编码实验优化记录

## 这次要解决的问题

图像编码实验此前有三个课堂使用问题：

1. 首页把图像编码做成默认入口，容易让学生误以为它比其他实验更重要。
2. 源图像选择器一次展示多张素材，学生需要先做“选哪张图”的额外决定。
3. 一些标题和任务描述使用了“因果链”“迁移解释”“载荷”等抽象或内部术语，不像教师可以直接布置给学生的语言。

本次改动把首页改成中性目录，把任务单保持为一个可折叠的原生 `details` 文档，并让图像实验默认只使用一张固定样例。任务单不再增加多层卡片或游戏化状态；页面只记录观察，学生仍由教师引导完成描述、计算和解释。

## 样例图片的选择

预设图片使用一张项目内生成的小猫图像，固定为 `240 × 160` RGB 栅格。图像随代码发布，不依赖远程文件。

选择它的理由：

- 深色背景与白色毛发形成清晰轮廓，降低采样后仍能看出主体变化。
- 两只颜色不同的眼睛和毛发边缘同时提供颜色差异、细节差异和局部高对比区域。
- 小猫插图是学生容易识别的画面，比抽象色块更容易引出“哪些信息先消失”的讨论。

## 从生成图像到本地样例

图片在开发阶段生成一次，随后按以下步骤处理：

1. 将图像固定为 `240 × 160`，给采样滑杆留下可见的变化空间。
2. 转换成 8-bit RGB 原始像素。
3. 将 RGB 字节以内嵌 Base64 形式写入 `src/features/image-encoding/domain/photo-rgb.ts`。
4. 运行时直接从本地字节生成 `RasterImage`，不请求远程图片、不依赖外部 CDN，也不把图片写入 URL。
5. 用稳定像素签名、颜色数量、相邻像素差异和采样/颜色数量变化测试确认结果可重复。

这样保留了课堂演示需要的离线、确定性和快速加载。

## 课堂界面取舍

- 首页不再出现图像编码专属 Hero、预览图或“进入图像编码”的推荐按钮；三个实验主题只做目录分组，入口等权。
- 图像实验的可见内置素材只有“小猫插图”。本地上传仍保留，学生可以选择上传自己的图片。
- 旧的 `image=gradient`、`image=checkerboard`、`image=text-edge` 和 `image=pixel-grid` URL 仍可解析，便于兼容旧链接和测试，但不再向学生展示长选项列表。
- 任务单继续使用一个原生折叠区，内容是简单的编号清单；“证据出现”只表示网页显示了观察结果，不表示学生已经完成答案。

## 人话审查记录

本轮又扫描了所有实验页的用户可见文案和无障碍名称，重点清理教师/学生角色话术、`workspace`、`检查器`、`证据`等内部表达。主要替换如下：

| 原表达                      | 改为                                           |
| --------------------------- | ---------------------------------------------- |
| 因果链                      | 原因和推导过程；按顺序说明每一步如何造成下一步 |
| 迁移解释                    | 联系实际                                       |
| 追踪一个像素到 bits         | 把一个像素拆成数字                             |
| 证据视图                    | 查看变化 / 观察视图                            |
| 机制实验                    | 动手实验                                       |
| 载荷                        | 原始数据量                                     |
| 状态数量                    | 可用颜色数                                     |
| 教师设定任务 / 学生调整参数 | 你需要调整参数、观察并记录结果                 |
| 检查器 / 证据               | 设置、信息、结果或步骤详情                     |
| neutral map / formalization | 页面目录 / 对现象的进一步说明                  |

代码中的领域字段、URL 参数、CSS 类名和测试标识仍保留英文或技术名称；只替换用户可见文案和无障碍名称。

## 验收标准

- 首页看不出某一个实验被特别推荐，且不再包含图像编码像素预览。
- 图像编码页面只出现一个固定内置样例；`image=photo` 默认与旧链接仍可用。
- 采样变小时，猫的轮廓和细节会变粗或丢失；颜色数量变少时，毛发和背景的颜色层次会减少。
- `100%` 采样配合“原色（RGB 24 位）”时，重建像素与原图逐像素一致；较低采样仍会产生空间信息损失。
- 无远程图片请求；本地服务可在无网络条件下运行。
- 任务单保持可折叠、单层、可读，不新增提交或游戏化流程。
- 受影响的单元测试、格式检查、类型检查、构建和单 worker 浏览器测试全部通过。
