# Frontend Core

- `src/app` owns TanStack Router setup, route loaders/errors, and page composition; see `src/app/router.tsx`.
- The audio-encoding demo has no API route to enforce access: its home card and direct page route both require an open `GET /api/labs` catalog entry.
- Labs own `domain/lesson/ui`; complex labs may add `controller/preview` (CPU pilot). Visual tasks consume ViewModel/actions and DEV-only fixtures; see `mem:cpu_lab` for its runtime boundary. Task sheets live under `src/features/task-sheets` and follow the same layering: `domain` schema/grade/validation, `lesson` editor state machine, `ui` editor/dashboard/preview components.
- `src/shared/{auth,api,layout,lab}` holds only cross-feature infrastructure with live consumers. Do not move lesson semantics into shared code.
- Autosave protocol: `useAutosaveDraft` PUTs `{draft, expectedRevision}`; the server assigns the next revision (OCC). Same-stage arms serialize behind the in-flight one — never send two writes concurrently. On `applied: false`, `fetchProject()` + `resolve-save-conflict` reconciles ONLY the conflicted stage in one reducer action; never chain `load-project` for conflicts (it clobbers other stages' dirty drafts and flags). `draftRevisions` per stage is seeded from `load-project` and bumped by `mark-saved.revision`.
- Full-page screens use `AppPageLayout` and `AppTopbar`; use shared page gutters and width tokens. `AppPageLayout` keeps `AppTopbar` outside its viewport-height `.page-layout-content` scroll region. More project-wide guidance: `mem:conventions`.
- `.page-layout` is viewport-locked (`height:100dvh; overflow:hidden`); `.page-layout-content` is the only scroll region (`flex:1 1 0; min-height:0`). Any surface that must flow to content height — the devtools preview (`.lab-preview-flow` in `devtools/lab-preview/lab-preview.css`), full-page captures — must unlock both rules.
- Sizing an iframe to its document in this repo: skip the throwaway `about:blank` document (it fires its own `load` then is replaced) via a persistent load listener, observe `documentElement`+`body` with ResizeObserver, and set the iframe `box-sizing: content-box` — global `border-box` makes `style.height` differ from the inner viewport by the border width.
- `AuthProvider.initialState` is mount-time only. To isolate a subtree from app auth (devtools previews), nest a provider — `PreviewAuthBoundary` in `devtools/lab-preview/LabPreviewPage.tsx` — which shadows context and fires no `/api/auth/me`.
