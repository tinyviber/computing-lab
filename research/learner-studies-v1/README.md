# Learner studies v1 archive

> **SUPERSEDED FOR LEARNING CLAIMS**

This is a visibly historical archive of the PR20 learner-study material. It is not the current learner-study authority. Use [learner-studies-v2 methodology](../learner-studies-v2/methodology.md) for current study design and [the research archive policy](../README.md) for research boundaries.

## Valid uses only

This archive may be used only for interaction observations, UI salience, terminology friction, and observable browser behavior.

## Forbidden uses

Do not use this archive as evidence of human comprehension, human learning gain, teacher silence, validated transfer, architecture, or a shared runtime.

The accompanying observation file preserves only the unique C direct observations selected from PR20. It intentionally omits learner conclusions, transfer answers, alignment claims, self-scores, P0 claims, and recommendations.
