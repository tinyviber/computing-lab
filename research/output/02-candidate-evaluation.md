# 02-candidate-evaluation：候选实验严格筛选（三视角独立评价汇总）

> **Historical selection record — not current implementation authority.** The candidate ranking and teaching constraints remain research evidence, but shared-infrastructure suggestions and current-code assertions predate the completed reference courses. Re-evaluate any implementation choice against the current `docs/` architecture and feature evidence.

- **日期**：2026-08-17
- **方法**：对阶段二 24 个候选实验，由 **Curriculum / Reviewer / Implementation** 三个视角**独立**评分（互不通信），每视角按 7 条标准（理解提升 / 交互必要性 / 实验闭环 / 课堂时间尺度 / 自主探索 / 基础设施共享 / 开发成本，各 1–5 分）评分并标注惩罚项，给出 S/A/B/C 分级。
- **汇总规则**（主 Agent 应用，明确可复核）：S = 三视角全 S 或 ≥2 S 且无 C；A = ≥2 A（含 1S+2A）且无 C；C = ≥2 C；其余 = B。A/C 并列时标注争议、按 A 计入但列为待裁决。
- **三视角独立评价**：课程、评审与工程三个视角的详细工作底稿未版本化；本汇总保留评分口径、矩阵、分歧与决策相关结论。

## 2. 最值得继续研究的实验（14 个 = 全部 S + A 级）

按共识强度与教学价值排序。**建议研究投入顺序：前三批**。

### 第一批（全票 S，建议优先深入研究与排期）

**E1 循环执行器**（3.11+3.4+3.16）｜S

- 价值：程序思维第一道认知坎；"s=s+item"、三要素缺一不可、死循环——静态讲解必然教不动。
- 形态硬约束：三要素（初值/终值/步长/方向）可编辑；单步执行显示每步变量新旧值与条件布尔结果；预测模式（先猜执行次数/结果）；死循环预警；**禁止被动播放**。
- 工程：无新原语；循环展开表=纯派生数据可测；与 3.16 下标联动零成本；执行步进/变量表模式同时服务 #19/#20/#21。

**E2 枚举·密码锁**（3.21+3.22）｜S

- 价值：单元挑战官方任务天然可交互；"位数+1、次数×10"指数感；破解时间化产生安全教育的情绪记忆。
- 形态硬约束：枚举的系统性（vs 乱猜）可见；剪枝前后尝试次数对比；10³ vs 26⁵ 空间数量级由学生自己得出结论；逐候选闪烁需降采样（只高亮命中前后轨迹）。
- 工程：纯循环计算、无解析器、成本最低档；对数柱状图依赖图表族原语。

**E3 筛选判定器**（2.11）｜S

- 价值：筛选=逐行布尔运算是 Excel 黑箱里唯一可揭示的机制；"隐藏非删除""多列筛选叠加"两个教材误解点一并击破；跨单元呼应 3.13 逻辑运算。
- 形态硬约束：**行级布尔判定可见**（每行显示"为什么被筛出/筛掉"，条件逐项拆解）；先预测某行留不留再验证；只显示结果行=与 Excel 无异=假交互。
- 工程：逐行派生数据纯函数可测；**表格网格原语首个载体**；条件构建器与 home-network combobox 同族；无定时器无特殊技术。

**E4 图像向量化**（4.5）｜S

- 价值："计算机看到的不是图，是一串数字"——AI 去魔法化第一课；顺序即位置（打乱图毁）。
- 形态硬约束：点像素→看灰度值→定位 784 向量中位置的一一对应操作体验；反向还原（改数组值看图变化）；示意样本注明"非真实 MNIST"。
- 工程：复用度全场最高（div grid 像素阵直接继承 image feature）；纯函数确定性变换；784 格渲染避免每帧重建。

**E5 蒙特卡洛投点 π**（3.12+3.15）｜S

- 价值："随机=不精确=没用"的心智模型只有亲手看到波动收敛才能击碎；3.15 效率对照作收尾面板零额外成本。
- 形态硬约束：**每个点的命中判定可见**（坐标、x²+y²<1、扇形内外——补上教材图 3-27 与 3-29 之间缺失的过程）；**种子可控**（直接服务教材思考题）；收敛曲线；只做落点动画则降级。
- 工程：种子 PRNG（~10 行）与 URL 复现机制契合；SVG ≤2000 点/Canvas 5000+（教学尺度上限+分批）；rAF 需 jsdom mock；收敛曲线依赖图表族原语。

### 第二批（S 级后半 + 高分 A）

**E6 进制位权**（1.7）｜S（Curriculum/Implementation 双 S，Reviewer A）

- 价值：项目二一切编码的地基、学业考试必考；位权格让"把二进制位当十进制位读"（1101=一千一百零一）的错误发生并修正。
- 形态硬约束：位权格 + 逐位判定 + 预测模式；纯转换器=计算器、竖式动画=被动观看，均判死；小数部分乘 2 取整需终止条件。
- 工程：纯整数算术 + div grid 位格；**bit 格原语首个载体**，后续 #2/#3 顺带。

**E7 公式求值可视化**（2.9）｜A（Curriculum 一票 S）

- 价值：第二单元教学价值最高；"公式存的是引用关系不是结果""嵌套 IF 按顺序命中即停"是考试高频错误点，Excel 黑箱里唯一网页能揭示的点。
- 形态硬约束：**严格只读"公式→展开式→逐值求值"，不做表格编辑 UI**（网页 Excel 克隆三输）；改源数据→看自动重算形成闭环。
- 工程：白名单解析器（SUM/AVERAGE/MAX/MIN/IF/嵌套 IF）+ 递归求值 + 循环引用检测——**全清单测试成本最高点**；固定教材小数据集；求值高亮用状态索引非定时器。

**E8 声音补强·真实试听**（1.13）｜A（Implementation 评 S：声音重做验收）

- 价值：听感是声音数字化区别于图像数字化的唯一感知通道；"采样率低→失真"必须耳朵验证；现有 1–8Hz 缩尺不可听会误导。
- 形态硬约束：真实频率 440Hz + 真实采样率（8k/22.05k/44.1k）+ WebAudio 播放；先预测音质再试听（盲测可选）；作为声音实验扩展而非新实验。
- 工程：WebAudio 生命周期、自动播放手势解锁、jsdom 无 AudioContext 的 mock 层、每帧渲染规避；与 course-model-reset"声音重做"合并执行。

### 第三批（A 级）

**E9 数据表设计**（2.7+2.8）｜A（三视角无分歧）

- 价值：字段设计→查询验证→发现答不了→修正的设计思维闭环；约束拒脏数据是真机制；直接服务教材活动 4.2/4.3。
- 形态硬约束：做"删字段后哪些问题答不了""违规录入被拒+原因"，不做网页版数据库工具。
- 工程：约束校验复用"validate→issues"模式（与 #4 同内核）；表格网格原语第二载体。

**E10 编码规则设计**（1.6）｜A（三视角无分歧）

- 价值：唯一性/排序性/专用含义可解析的校验反馈是教材图 1-15 给不了的；直接服务教材活动 2.1"设计学籍号规则"。
- 形态硬约束：规则→校验→修正闭环；做成"解析器/看规则演示"则降级为会动的图。
- 工程：复用 home-network 判定模式；判定标准须约束为小字段集（学籍号/树牌号）。

**E11 图表类型匹配**（2.5）⚠条件 A

- 价值：让"可视化降低读数据认知负荷"（教材核心主张）可亲身体验；读图任务直接对应教材学业要求。
- 形态硬约束：**体验任务而非选择题库**——同一数据表格 vs 图表并置限时找规律 + 图型选错误导结论的反例；切换器与匹配选择题均判死；图型收缩到 3–4 种。
- 工程：SVG 图表族原语奠基实验（轴/刻度/图例共享子组件），图表族本身是 E5/E2 的前置依赖。

**E12 补码自洽性**（1.8）｜A

- 价值："取反加一"从死记配方变成可观察的设计动机（1+(-1)=0、进位丢弃可见、0 唯一）。
- 形态硬约束：只做补码加法自洽性；位翻转器=把表 1-3 变手动操作；**超纲需教师确认**（教材仅"了解"层级）。
- 工程：bit 格就绪后 1–2 天顺带；JS 位运算 32 位语义（`>>>0`）是单测重点。

**E13 图像补强·真实图片**（1.16/1.17）｜A

- 价值：真实照片的色阶断层比 8×8 合成图更有说服力（具身认知）。
- 形态硬约束：内置演示图库（非上传）；"参数→同一照片双图对照→总结"闭环；合入图像重做（冻结顺序中图像最后迁移）。
- 工程：直接复用现有采样/量化管线；canvas toDataURL 跨浏览器差异需测试容差。

**E14 文本编码链**（1.10–1.12）⚠争议 A

- 价值：只有三合一形态成立——1.11"冲突演示"（"大"的国标码按 ASCII 读成"4s"）与 1.12 中英混排逐字节对照是学生脑内无法可视化的点；单独做 ASCII 查表=把图 1-16 变成输入框。
- 形态硬约束：必须一条链（字符→编码→字节），含冲突演示；拆开即降级。
- 工程：bit 格第三载体；成本大头在 GB2312 区位码与 UTF-8 代理对（U+0041/U+4E2D/U+1F600）fixture 核对。

## 3. 争议与待裁决项（4 项）

1. **#23 训练曲线（4.6）**：三视角一致 C（伪模型假交互），但 Reviewer 保留**"真实可计算小模型"复活路径**（浏览器内逻辑回归/感知机于 MNIST 子集，200–400 行纯 JS，曲线真实计算、Q1/Q4 可过），代价：线性模型≠教材 CNN 需明示、小模型不收敛是常态需教学铺垫。**建议**：默认不做；若团队愿意投入真实模型，作为独立平台决策另行评审。
