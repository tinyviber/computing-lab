## 2. 全票收敛区：四角色一致认同的候选（详细多视角卡片）

以下候选通过 A 的必要性、B 的闭环设计、C 的成本评估、D 的四问攻击，争议仅在形态细节。

### 🥇 C1 循环执行器 — 3.11 累加循环 + 3.4 控制结构 + 3.16 列表（合并实验）

- **A**：高价值（程序思维第一道认知坎；"s=s+item"当场崩溃；三要素缺一不可；静态讲解教不动）。教学目标："循环=初值+终值+变化；累加器从 0 开始（累乘从 1）；没有让控制变量变化的语句就死循环"。
- **B**：三要素滑块（N14）+ 逐次累加播放头（N5）+ 循环展开表（每步 i/s/item）+ 阶梯曲线（N12）+ 死循环故障注入（N3）；变体"循环走格子"（具身步进）。
- **C**：复杂度中；复用 3.4 执行高亮、3.7 变量表、FormulaPanel；循环展开表是纯静态派生数据可测；无特殊技术；教学尺度 ≤20 行展开。
- **D**：终选 #1。三要素**可编辑** + **单步执行**（每步变量新旧值与条件布尔结果可见，Q1 过）+ **预测模式**（先猜执行次数/结果，Q3 过）+ 死循环预警（Q2 过）+ 可检验假设（"初值 1 终值 10 结果应为 55？"，Q4 过）。**禁止被动播放动画**。
- **争议**：无实质争议；D 要求 3.4 一并并入且禁止播放模式，B 的"播放头"需以"显式步进"实现。

### 🥇 C2 蒙特卡洛投点·随机模拟 — 3.12 随机投点法算 π + 3.15 算法效率对比（合并实验）

- **A**：高价值（"随机=不精确=没用"是认知冲突最强的误解；必须亲手看到"每次不同但越来越多越准"才信；教材图 3-29 只是两张静态图）。课堂实操提示：**同一投点数多次重投的结果分布 + 误差带**比单次结果更有教学力。
- **B**：投点画布 + 投点数滑块（对数刻度）+ 单点投掷 + 随机种子控制（N11）+ 批量投点播放头（N5）+ π 估计收敛曲线（N12）+ 不同种子并排对照（N2）。
- **C**：复杂度中；SVG ≤2000 点 / Canvas 5000+；**必须种子 PRNG**（否则 URL 场景不可复现）；rAF 在 jsdom 需 mock；a11y 用 hits/darts/π 统计文本作画布等价。
- **D**：终选 #2。硬性要求：**每个点的命中判定可见**（坐标、x²+y²<1、扇形内外——静态图 3-27 与结果图 3-29 之间缺失的过程）+ **种子可控**（直接服务教材思考题"同样 1000 点为何不同、如何减少不确定性"）。只做落点动画则降级。
- **争议**：B 的"误差/收敛曲线"与 C 的"图表组件族"互相印证；D 反对 3.15 的"真实计时"（JS 计时在教材缩尺下粒度不可靠），C 同样建议用步数/理论复杂度代替真实耗时——一致。

### 🥇 C3 枚举法·密码锁 — 3.21 枚举法 + 3.22 单元挑战密码安全（合并实验）

- **A**：高价值（单元挑战官方任务就是"输出猜中密码的尝试次数"——天然可交互；"位数+1、次数×10"的指数感几乎为零；破解过程时间化产生安全教育的**情绪记忆**）。
- **B**：枚举器（设定范围 + 验证条件 + 逐一检验播放头）+ 候选空间网格 + 剪枝对比（N2 缩范围前后次数）+ 密码锁转盘动画 + 10³ vs 26⁵ 空间柱状图（对数刻度）。
- **C**：复杂度低–中；纯循环计算（10³=1000 瞬时完成）；逐候选闪烁在 1000 次时体验差（只高亮命中前后轨迹或降采样）；"尝试次数"语义需与教材一致（顺序枚举 vs 随机）。
- **D**：终选 #3。枚举的**系统性**（与人类乱猜对比可见，Q1 过）+ 剪枝前后尝试次数对比（Q3/Q4 过）+ 空间数量级直观化（10³ vs 26⁵，教材思考题由学生自己得出结论）。
- **争议**：无实质争议。

### 🥇 C4 图像向量化 — 4.5 数据预处理（灰度→矩阵→一维数组）

- **A**：高价值（"机器看到的不是图，是数字"的认知反转；顺序即位置，打乱图就毁了；AI 去魔法化第一课）。
- **B**：手写板（N9 画笔）+ 28×28 灰度网格 + 蛇形展开动画（N4）+ 像素-矩阵元素-数组下标三级联动高亮 + 反向还原（改数组值看图像变化）。
- **C**：复杂度低–中；复用图像实验的 div grid 范式（784 格可行，避免每帧重建）；示意样本需注明"非真实 MNIST"；784 格 a11y 需分组语义。
- **D**：终选 #5。静态图 4-7 展示映射**结果**，交互提供"点像素→看数值→定位向量位置"的映射**操作体验**（Q3 过）；成本低、复用网格范式。
- **争议**：无实质争议。注意 A 曾建议 4.5+4.6 合并，但 D 毙掉了 4.6（见 §3.1），故本实验独立成立。

### 🥇 C5 筛选条件判定器 — 2.11 表格筛选（呼应 3.13 条件表达式）

- **A**：可选（操作型技能真实工具可练），但"隐藏非删除""多列筛选叠加"两个误解点清晰。
- **B**：条件构建器（N7 拼图：字段+运算符+值、AND/OR）+ 范围滑杆（N14）+ 行隐现动画 + 条件表达式实时回显。
- **C**：复杂度中；条件语义分派（包含子串 vs 值域）为定制逻辑；建议教学尺度只用文本/数值条件。
- **D**：终选 #4（**本单元唯一通过全部攻击的"高"标条目**）。硬性要求：**行级布尔判定可见**——每一行显示"为什么被筛出/筛掉"，条件逐项拆解；先预测某行留不留再验证。若只显示结果行高亮 = 与 Excel 无异 = 假交互。
- **争议**：A 判"可选"、D 判"真正值得做"——分歧点在"真实表格软件可练"vs"行级判定机制是黑箱"。D 论证更依赖"机制揭示"原则。

### 🥇 C6 位权·进制转换 — 1.7（有条件形态）

- **A**：高价值（项目二一切编码的地基；"除 2 取余要倒着读"必须逐步可视化纠偏；学业考试必考）。
- **B**：联动计数器（十/二/八/十六进制四屏翻转）+ 位权条 + 竖式动画 + "位权天平"游戏变体。
- **C**：复杂度低–中；复用 div grid 位格；纯整数算术；注意小数部分乘 2 取整需终止条件（8 位截断）。
- **D**：有条件重设计——**唯一可接受形态是"位权格 + 逐位判定 + 预测模式"**（允许"把二进制位当十进制位读"的错误发生并修正）；纯转换器 = 计算器 = 假交互；"除 2 取余"动画 = 把教材图 1-23/1-24 播放一遍 = 被动观看。优先级排在终选 5 个之后。
- **争议**：**A 判高价值第一优先 vs D 判有条件重设计且优先级后置**——分歧点：静态图能讲清多少（D 认为教材图已完整，A 认为"余数流"动态过程静态图给不了）。

### 🥇 C7 公式求值可视化 — 2.9 表格公式/函数（有条件形态）

- **A**：高价值（第二单元唯一高价值；"公式存的是引用关系不是结果""嵌套 IF 按顺序命中即停"考试必考且错误率最高）。
- **B**：迷你表格 + 公式求值逐步动画（N5：=SUM(A1:A3) 区域高亮逐格吸入）+ 嵌套 IF 解析树（N4）+ 错误标注（N3）+ 嵌套 IF 拼图（N7）。
- **C**：复杂度中–高（公式解析器是测试成本最高点，须白名单化）；固定教材同款小数据集（停车费/气温）；表格网格是值得做的新通用原语。
- **D**：有条件重设计——**仅限"公式→展开式→逐值求值"可视化，明确不做表格编辑 UI**（网页 Excel 克隆三输：成本爆表+重复真实工具+做得更差）；"引用-重算"是真实工具黑箱里唯一网页能揭示的点。
- **争议**：A 与 D 对"做不做"一致（都认为值得），但形态范围有分歧（B 的"迷你可编辑表格"vs D 的"只读求值展开"）。

## 3. 争议区：角色间显著分歧（如实保留，不做裁决）

### 3.1 4.6 训练正确率曲线 —— 本阶段最大分歧

- **A（做）**：高价值。真实 CNN 训练课堂跑不动，教材只能给静态曲线（图 4-9）；"参数-曲线"模拟是**唯一能让每个学生亲手体验'学习是渐进过程'的途径**——"不做就教不动"（资源不可得型）。
- **B（做）**：训练控制台（迭代/批大小/学习率）+ 双曲线（训练 vs 验证）+ 过拟合提示（N3）+ 超参赛跑（N2）。
- **C（可做但有条件）**：确定性伪训练曲线生成（sigmoid 上升 + 种子噪声的 domain 纯函数）；UI 必须明示"模拟而非真实 CNN"；动画计时器测试需 mock。
- **D（放弃，头号击杀）**：脚本曲线 = **伪模型假交互的教科书案例**（反馈不揭示机制 Q1 否、假设无法检验 Q4 否——"拖学习率看曲线"与"拖音量看亮度"认知上无异）；真实小模型成本高且模型（线性）≠ 教材 CNN，教学错位；教材活动 9.3 已有真实训练路径。**唯一复活条件**：承诺真实可计算的小模型 + 明确标注与 CNN 差异——成本远超收益，不建议。
- **争议本质**："资源不可得的唯一模拟途径"（A）vs "伪造数据的教学危害"（D）。D 的护栏 1（禁伪模型）若被采纳，4.6 只能以"真实可计算模型"或"静态图变体"形式存在。

### 3.2 2.10 排序 —— inventory 标"高"，D 判放弃

- **B**：排序动画剧场 + 手动排序挑战（记录步数对比最优）。
- **C**：低–中复杂度（复用表格模拟器，排序动画用步进索引）。
- **D（放弃，强烈）**：教材只要求"用排序工具按关键字排序"（图 2-37 是工具截图），**教材不教任何排序算法**——动画展示的是冒泡/选择排序细节，学生看完说不出任何本教材结论；做"工具模拟"则 Q1/Q3 全否。排序算法可视化属于其他课程内容。
- **A**：可选（真实 Excel 可练；交互增益只在"多关键字"一处，可在 2.9 实验里顺带做一个面板）。
- **倾向**：A、D 均不主张独立实验；B 的动画形态被 D 直接否定。

### 3.3 3.3 流程图 —— A 高价值 vs D 降级（绘制）、C 编辑器后置

- **A**：高价值（与 3.4 合并；"执行感"只能靠单步执行建立；学生读流程图脑内跑不起来）。
- **B**：流程图编辑器（N7 拖拽符号连线 + 运行模拟执行轨迹 N5）+ 残缺图修补。
- **C**：只读渲染器值得做（通用原语）；**编辑器高成本后置**（拖拽测试不稳、自动布局是图算法问题、对键盘用户极难）。
- **D**：降级——符号识别是记忆性知识（表 3-1 + 图 3-8 已完整）；编辑器是真实工具重复劳动；**流程图的真价值在执行，执行可视化属于 3.4**（已并入 C1 循环执行器）。
- **收敛点**：三个角色的交集是"流程图执行可视化（并入循环执行器）值得做，流程图编辑器不值得/后置"。

### 3.4 2.5 数据可视化（图表类型）—— A 可选第一 vs D 有条件重设计

- **A**：可选档第一位（教学增益大：同一数据多图切换把"图表选择"从记忆变成操作观察）。
- **B**：类型轮盘 + 字段拖拽映射 + "可视化挑错"（误导性图表找茬）。
- **C**：SVG 图表组件族值得做（服务 2.5/2.4/2.14/3.12/4.6）；手写六图可控，不引 ECharts。
- **D**：有条件重设计——**必须是"数据-图型匹配判定 + 读图任务"**（同一数据表格 vs 图表并置限时找规律；图型选错误导结论的错误案例）；"同一数据切换图表类型看动画" = 图表库渲染演示（Q1 弱、Q3 否）。图型范围收缩到 3–4 种。
- **争议本质**：图表切换器是"渲染演示"还是"认知体验"。

### 3.6 其他小分歧（简要）

1. **最高优先无争议**：第三单元三个实验——循环执行器（3.11+3.4+3.16）、投点 π（3.12+3.15）、枚举·密码锁（3.21+3.22）——四角色全票，且共享"执行/过程可见"这一机制内核与 C 的通用原语。

3. **第二单元以"表格网格 + 机制揭示"为主线**：2.11 筛选判定器（D 终选）、2.9 公式求值（有条件）、2.7+2.8 数据表设计（D 重设计、C 低复杂度）、2.12 透视表聚合（有条件）；2.10 排序被 D 否、A 不主张独立。
