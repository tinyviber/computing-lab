# Cross-lab successful patterns

- Same-display comparisons make hidden variables visible: same image size, same audio duration, same network topology, same bit width, same program fixture, same N with different seed.
- Immutable event traces let learners reconstruct causality instead of trusting a final verdict.
- Before/after evidence and selected intermediate frames support teach-back.
- Fixed edge-case presets provide counterexamples cheaply: aliasing, overflow, packet loss, invalid UTF-8, broken FK, and one-byte corruption.
- Provenance-style views answer “which input caused this output?” across image pixels, route hops, program frames, byte groups, and database rows.
- Honest metrics help: Monte Carlo shows seed/repetition and non-monotonic paths; Protocol shows retries and duplicate suppression; Two's Complement separates carry-out from signed overflow.
- Transfer prompts reveal understanding better than navigation or page-confidence scores.
