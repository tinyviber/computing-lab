# Emerging course-flow vocabulary

## Reusable flow

**Hook → Commit → Perturb → Step → Inspect → Contrast → Name → Transfer.**

- Hook: expose a puzzle (“same four visible characters, ten bytes”; “late ACK: did it fail?”).
- Commit: learner predicts before evidence.
- Perturb: change one meaningful variable or fixture.
- Step: expose the smallest causal transition.
- Inspect: point to the intermediate artifact that explains the outcome.
- Contrast: compare a nearby counterexample.
- Name: teacher or page supplies formal vocabulary.
- Transfer: unseen case plus teach-back.

## Where current labs fit

Program and UTF-8 naturally support the full flow. Image, Two's, Monte Carlo, and Byte Edit support it with a teacher prompt. Audio, Home Network, Protocol, and Relational Data need clearer vocabulary and boundary labels before the same flow can run with teacher silence.

## Teacher move

Ask “What changed first?” and “What did the system know at that moment?” These two questions work across pixels, samples, routes, bits, statements, queues, code points, random batches, rows, and byte groups.
